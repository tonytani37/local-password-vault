# 最初にお読みください。

## 本処理は、ローカル単独モードとクラウド（cloudflare R2）連携モードの２つの環境で動作します。

### 起動ファイルによるモード切替と環境変数

配布時の `start.bat`（および `start.sh`）には、あらかじめ以下の環境変数設定欄が**空文字（未記入）**の状態で用意されている。

- **初期状態（すべて空欄のまま起動）**：外部通信を一切行わない「**ローカル単体モード**」として即座に起動する。クラウド環境を用意しない利用者は、起動ファイルを編集せずそのままダブルクリックするだけで利用できる。
- **Cloudflare R2 同期を利用する場合**：起動ファイルをテキストエディタで開き、R2関連の4項目（`R2_ACCOUNT_ID`, `R2_BUCKET`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`）に自身の値を記入して保存することで「**Cloudflare R2 同期モード**」に切り替わる。

| 変数名 | 必須/任意 | 内容 |
|---|---|---|
| `R2_ACCOUNT_ID` | 任意（R2利用時は必須） | Cloudflare のアカウントID |
| `R2_BUCKET` | 任意（R2利用時は必須） | 保存先の Cloudflare R2 バケット名 |
| `R2_ACCESS_KEY_ID` | 任意（R2利用時は必須） | R2 API トークンのアクセスキーID |
| `R2_SECRET_ACCESS_KEY` | 任意（R2利用時は必須） | R2 API トークンのシークレットアクセスキー |
| `R2_OBJECT_KEY` | 任意 | R2上の保存ファイル名（デフォルト: `vault.db`） |
| `VAULT_DB_PATH` | 任意 | ローカルの `vault.db` 保存先パス（デフォルト: `server.mjs` と同階層） |
| `VAULT_BACKUP_DIR` | 任意 | ローカルのバックアップ保存先フォルダ（デフォルト: `server.mjs` 配下の `backups`） |

※ 4項目のうち1つでも空欄がある場合は「ローカル単体モード」となる。4項目すべてに値が入っている状態で認証情報やネットワークに不備がある場合は、安全のため後述の「オフライン閲覧専用モード」へ自動移行する
