# 最初にお読みください。

### システムの開始方法

#### 1. ローカル単体モードで起動する場合（初期状態）
1. 配布フォルダ内の **`start.bat`**（macOS / Linux の場合はターミナルから **`./start.sh`**）をダブルクリックして実行します。
2. 黒いコンソール画面が開き、`Password Vault server listening on http://localhost:3000 [ローカル単体モード]` と表示されます。
3. 約2秒後に既定のWebブラウザが自動的に起動し、管理画面（`http://localhost:3000`）が表示されます。
   - ブラウザが自動で開かない場合や誤って閉じた場合は、ブラウザのアドレスバーに `http://localhost:3000` を直接入力してください。
4. 初回起動時は12文字以上のマスターパスワードを設定し[cite: 1, 2]、2回目以降は設定したマスターパスワードを入力してログインします。

#### 2. Cloudflare R2 同期モードで起動する場合（任意）
1. 事前に `start.bat`（macOS / Linux の場合は `start.sh`）をメモ帳などのテキストエディタで開き、冒頭の `R2_ACCOUNT_ID`・`R2_BUCKET`・`R2_ACCESS_KEY_ID`・`R2_SECRET_ACCESS_KEY` に自分のR2接続情報を記入して保存します（詳細は `R2_SETUP.md` を参照）。
2. **`start.bat`**（または **`start.sh`**）を実行します。
3. コンソールに `[Cloudflare R2 同期モード]` と表示され、自動的にブラウザで `http://localhost:3000` が開きます。
   - インターネット未接続などでR2へ接続できない場合は、自動的に `[オフライン閲覧専用モード]` で起動します。

> **注意:** サーバー稼働中、黒いコンソール画面は開いたままにしておいてください。最小化しても問題ありません。

### システムの終了方法

1. ブラウザ画面で「ログアウト」をクリックし、タブを閉じます（任意）。
2. アプリを起動している黒いコンソール画面（コマンドプロンプト／ターミナル）をクリックして選択し、**`Ctrl + C`** を押します。
   - Windows で `バッチ ジョブを終了しますか (Y/N)?` と表示された場合は、`Y` を入力して `Enter` キーを押してください。
3. コンソールに `バックアップ完了` と表示され、サーバーが停止したことを確認します。

> **注意:** コンソール画面の右上「×」ボタンで直接ウィンドウを閉じると、終了時の自動バックアップ処理が正常に実行されない場合があります。必ず `Ctrl + C` で終了してください。


### 起動ファイルによるモード切替と環境変数

配布時の `start.bat`（および `start.sh`）には、あらかじめ以下の環境変数設定欄が**空文字（未記入）**の状態で用意されている。

- **初期状態（すべて空欄のまま起動）**：外部通信を一切行わない「**ローカル単体モード**」として即座に起動する。クラウド環境を用意しない利用者は、起動ファイルを編集せずそのままダブルクリックするだけで利用できる。
- **Cloudflare R2 同期を利用する場合**：起動ファイルをテキストエディタで開き、R2関連の4項目（`R2_ACCOUNT_ID`, `R2_BUCKET`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`）に自身の値を記入して保存することで「**Cloudflare R2 同期モード**」に切り替わる。

| 変数名 | 必須/任意 | 内容 |
|---|---|---|
| `R2_ACCOUNT_ID` | 任意（R2利用時は必須） | Cloudflare のアカウントID |
| `R2_BUCKET` | 任意（R2利用時は必須） | 保存先の Cloudflare R2 バケット名 |
| `R2_ACCESS_KEY_ID` | 任意（R2利用時は必須） | R2 API トークンのアクセスキーID |
| `R2_SECRET_ACCESS_KEY` | 任意（R2利用時は必須） | R2 API トークンのシークレットアクセスキー |
| `R2_OBJECT_KEY` | 任意 | R2上の保存ファイル名（デフォルト: `vault.db`） |
| `VAULT_DB_PATH` | 任意 | ローカルの `vault.db` 保存先パス（デフォルト: `server.mjs` と同階層） |
| `VAULT_BACKUP_DIR` | 任意 | ローカルのバックアップ保存先フォルダ（デフォルト: `server.mjs` 配下の `backups`） |

※ 4項目のうち1つでも空欄がある場合は「ローカル単体モード」となる。4項目すべてに値が入っている状態で認証情報やネットワークに不備がある場合は、安全のため後述の「オフライン閲覧専用モード」へ自動移行する

※ Cloudflare R2関連情報の説明は **./docs/cloudflareR2セットアップガイド.md** を参照してください。
