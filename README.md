# 最初にお読みください。

### システムの開始方法

#### 1. ローカル単体モードで起動する場合（初期状態）
1. 配布フォルダ内の **`start.bat`**（macOS / Linux の場合はターミナルから **`./start.sh`**）をダブルクリックして実行します。
2. 黒いコンソール画面が開き、`Password Vault server listening on http://localhost:3000 [ローカル単体モード]` と表示されます。
3. 約2秒後に既定のWebブラウザが自動的に起動し、管理画面（`http://localhost:3000`）が表示されます。
   - ブラウザが自動で開かない場合や誤って閉じた場合は、ブラウザのアドレスバーに `http://localhost:3000` を直接入力してください。
4. 初回起動時は12文字以上のマスターパスワードを設定し、2回目以降は設定したマスターパスワードを入力してログインします。

#### 2. Cloudflare R2 同期モードで起動する場合

本システムでは、複数端末からの利用を想定したモードを準備しています。
それはR2のアクセスキーを起動ファイル（平文）に直書きせず、 **マスターパスワード由来の暗号鍵で暗号化してデータベース（`vault.db`）内に安全に保存する方式（CLI登録）** で提供しています（R2バケットおよびAPIトークンの準備手順は `/docs/cloudflareR2セットアップガイド.md` を参照してください）。

##### A. 推奨方式：CLIコマンドでDB内に暗号化保存して利用する
1. 先に「1. ローカル単体モード」で起動し、ブラウザからマスターパスワードの初期設定を完了させてからサーバーを終了（`Ctrl + C`）します。
2. コマンドプロンプト（Windows）またはターミナル（macOS / Linux）で配布フォルダへ移動し、以下のセットアップコマンドを実行します。
   ```bash
   node server.mjs --setup-r2
   ```
3. 画面の案内に従って以下の項目を入力します（入力完了後、自動的にR2への接続テストが行われます）。
   - **マスターパスワード**（最初にログインように入力したもの）
   - **R2 Account ID**
   - **R2 バケット名**
   - **R2 Access Key ID**
   - **R2 Secret Access Key**
   - **R2 オブジェクトキー**（省略時は `vault.db`）

### CLI入力の表示仕様について
`node server.mjs --setup-r2` 実行時のプロンプトでは、貼り付け（コピペ）時の入力ミスを防ぐため、マスターパスワードおよび R2 Secret Access Key を含むすべての入力項目が画面上にそのまま表示されます（設定完了後、画面上の履歴を消去したい場合は `cls` または `clear` コマンドを実行してください）。

#### CLIプロンプトで貼り付け（Ctrl+V）がうまくいかない場合
Windows の古いコマンドプロンプト環境などでは、`Ctrl + V` を押すと `^V` と表示されて貼り付けができない場合があります。その際は以下のいずれかの方法で貼り付けてください。

* **Windows（コマンドプロンプト / PowerShell / Windows Terminal）:**
  * ターミナル画面内の任意の場所を**右クリック**する（簡易編集モードが有効な場合、右クリックだけでクリップボードの内容が貼り付けられます）。
  * **`Shift + Insert`** キーを押す。
  * ウィンドウ左上のアイコンをクリックし、メニューから **「編集」＞「貼り付け」** を選択する。
* **macOS（ターミナル）:**
  * **`Cmd + V`** を押す、または画面内の任意の場所を**右クリック（2本指クリック）して「ペースト」**を選択する。
  
### 複数PCでの利用・環境移行について
すでにR2設定を完了したPCから別のPCへ同じ環境を構築したい場合は、**配布フォルダごと（暗号化済みの `vault.db` を含めて）コピーするだけ**で移行できます。`vault.db` 内にはパスワードデータとともにR2接続情報もマスターパスワード由来の鍵で暗号化されて保存されているため、コピー先のPCで起動ファイルに環境変数を記述する必要はありません（そのまま起動してマスターパスワードでログインするだけで自動的にR2同期が有効になります）。

※ `vault.db` をコピーせずプログラム本体だけを新PCに配置し、クラウド（R2）上の既存データベースを初回ダウンロード復元したい場合のみ、一時的に起動ファイルへ環境変数を指定して起動してください。


4. 接続テストに成功すると、設定情報がマスター鍵で暗号化されて `vault.db` に保存されます。
5. 以降は普段通り **`start.bat`**（または **`./start.sh`**）を実行するだけで、`[Cloudflare R2 同期待機モード (ログイン後に有効化)]` として起動し、ブラウザでログインした瞬間にクラウド同期が有効になります。
   - インターネット未接続などでR2へ接続できない場合は、自動的にオフライン閲覧専用モードへ切り替わります。

**【R2連携を解除したい場合】**
サーバー停止中に以下のコマンドを実行すると、`vault.db` 内のR2設定が削除されローカル単体モードに戻ります。
```bash
node server.mjs --clear-r2
```

##### B. 代替方式：起動ファイルの環境変数で指定する場合
新PCでローカルに `vault.db` がまだ存在しない状態から初回ダウンロード復元を行いたい場合などは、起動ファイルに直接環境変数を指定して起動することも可能です（環境変数が指定されている場合は、DB内の設定より環境変数が優先されます）。

1. `start.bat`（macOS / Linux の場合は `start.sh`）をメモ帳などのテキストエディタで開き、冒頭の `R2_ACCOUNT_ID`・`R2_BUCKET`・`R2_ACCESS_KEY_ID`・`R2_SECRET_ACCESS_KEY` に自分のR2接続情報を記入して保存します。
2. **`start.bat`**（または **`start.sh`**）を実行すると、起動直後にR2と同期し `[Cloudflare R2 同期モード (環境変数)]` で起動します。
   - ※ローカルへ `vault.db` の復元が完了した後は、セキュリティ確保のため手順 A（`--setup-r2`）へ切り替え、起動ファイルからキーの記述を削除することを推奨します。

> **注意:** サーバー稼働中、黒いコンソール画面は開いたままにしておいてください。最小化しても問題ありません。

### システムの終了方法

1. ブラウザ画面で「ログアウト」をクリックし、タブを閉じます（任意）。
2. アプリを起動している黒いコンソール画面（コマンドプロンプト／ターミナル）をクリックして選択し、**`Ctrl + C`** を押します。
   - Windows で `バッチ ジョブを終了しますか (Y/N)?` と表示された場合は、`Y` を入力して `Enter` キーを押してください。
3. コンソールに `バックアップ完了` と表示され、サーバーが停止したことを確認します。

> **注意:** コンソール画面の右上「×」ボタンで直接ウィンドウを閉じると、終了時の自動バックアップ処理が正常に実行されない場合があります。必ず `Ctrl + C` で終了してください。

### 起動ファイルによるモード切替と環境変数

配布時の `start.bat`（および `start.sh`）には、あらかじめ以下の環境変数設定欄が**空文字（未記入）**の状態で用意されています。

- **初期状態（すべて空欄のまま起動）**：外部通信を一切行わない「**ローカル単体モード**」として即座に起動します。クラウド環境を用意しない利用者は、起動ファイルを編集せずそのままダブルクリックするだけで利用できます。
- **CLI（`--setup-r2`）でR2設定を保存済みの場合**：起動ファイルは空欄のまま変更不要です。起動時は「**Cloudflare R2 同期待機モード**」となり、ログイン認証の成功と同時にDB内のR2設定が復号され同期が開始されます。
- **環境変数でR2設定を指定する場合**：起動ファイルをテキストエディタで開き、R2関連の4項目（`R2_ACCOUNT_ID`, `R2_BUCKET`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`）に値を記入して保存することで、起動時から「**Cloudflare R2 同期モード (環境変数)**」に切り替わります。

| 変数名 | 必須/任意 | 内容 |
|---|---|---|
| `R2_ACCOUNT_ID` | 任意（環境変数方式時は必須） | Cloudflare のアカウントID |
| `R2_BUCKET` | 任意（環境変数方式時は必須） | 保存先の Cloudflare R2 バケット名 |
| `R2_ACCESS_KEY_ID` | 任意（環境変数方式時は必須） | R2 API トークンのアクセスキーID |
| `R2_SECRET_ACCESS_KEY` | 任意（環境変数方式時は必須） | R2 API トークンのシークレットアクセスキー |
| `R2_OBJECT_KEY` | 任意 | R2上の保存ファイル名（デフォルト: `vault.db`） |
| `VAULT_DB_PATH` | 任意 | ローカルの `vault.db` 保存先パス（デフォルト: `server.mjs` と同階層） |
| `VAULT_BACKUP_DIR` | 任意 | ローカルのバックアップ保存先フォルダ（デフォルト: `server.mjs` 配下の `backups`） |

※ 環境変数方式では、4項目のうち1つでも空欄がある場合は環境変数によるR2接続は無効となります。また、CLI方式・環境変数方式のいずれにおいても、認証情報やネットワークに不備がある場合は、安全のため「オフライン閲覧専用モード」へ自動移行します。
